The core idea is to automate attendance using RFID (Radio Frequency Identification) technology, eliminating manual logs and providing real-time data to a central dashboard.

Important:
    To understand how the UID (Unique Identifier) moves from a physical card into your Python logic, we have to look at two different communication "languages" happening at the same time: **SPI** and **UART Serial**.


1. Extraction: How the ESP32 gets the UID (The Hardware Step)
The RFID card doesn't actually "send" data on its own; it is passive. It waits for the RC522 to create an electromagnetic field.

Induction:When you tap the card, the RC522 sends out a 13.56MHz radio signal. This signal powers up the tiny chip inside your ID card.
The Handshake:The card wakes up and transmits its hard-coded UID (usually a 4-byte or 7-byte hex string like `A1 B2 C3 D4`) back to the reader via radio waves.
SPI Protocol:The RC522 translates these radio waves into digital bits. It then "talks" to the ESP32 using the SPI (Serial Peripheral Interface) protocol. 
    * The ESP32 acts as the Master and the RC522 as the Slave. 
    * The data travels over the `MISO` (Master In Slave Out) line directly into the ESP32's memory.



---

2. Transmission: How ESP32 sends it to Python (The Software Step)
Once the ESP32 has the UID in its memory, it needs to get it to your computer. Since your code uses a USB cable, it uses UART (Universal Asynchronous Receiver-Transmitter) communication.

The String Formatting: `Serial.print("UID: "); Serial.println(uidString);`
Serial Buffer:The ESP32 converts that text into a series of voltage pulses (0s and 1s) and sends them through the USB cable at a speed of 115,200 bits per second (BAUD_RATE).
The Python Catch: "listening" to `COM5`.
    `ser.readline()` waits until it sees a "newline" character (`\n`).
    It grabs the whole line: `"UID: A1B2C3D4\r\n"`.

---

3. Processing: How Python extracts the "Clean" UID
The data arriving in Python is "dirty"—it contains extra text and hidden formatting characters. Your script cleans it using these steps:

1. Decoding:`.decode('utf-8')` converts the raw bytes from the USB cable into a readable Python string.
2. Stripping:`.strip()` removes the hidden `\r\n` (carriage return/newline) from the end.
3. Filtering: `raw_line.replace("UID: ", "")` removes the label so you are left with just the actual ID: `A1B2C3D4`.
